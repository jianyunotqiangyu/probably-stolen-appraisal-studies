## 六、占格与渲染（已定位）

| # | 现象 | 根因 | 结论 |
|---|---|---|---|
| G1 ✅ | 纪念币能互相重叠、选中时没有格子高亮 | `GameItem.SetSpriteAndShapeFromMod` 用**每个格子中心像素**的 alpha 推导占格（16×16 图标只采样 (8,8)）。图标取的是「两枚币并排」的整图，中心正好落在两枚之间的空隙 → alpha=0 → **占格形状为空** → 物品不占格子，于是可重叠、无高亮 | 图标必须取**单枚币**（左半边），并保证中心不透明；另加 `ItemFootprint.Ensure` 兜底为 1×1 |
| G2 ✅ | 镜片里编号字距异常变宽 | 字符层偏移按「面板尺寸」换算，但镜片副本的 rect 尺寸不同（且整体还有 `LensScale`） | 偏移改为按**层所在父节点**尺寸换算 |

| G3 ✅ | 镜片放大倍数怎么定 | 原版预制体实测：面板侧各物品块 localScale=1，镜片侧同名块 localScale=2。这个 2 是**相对面板**的比值，不是相对原图像素。我们面板把 256 画成 440，镜片乘 2 → 880（3.44× 原生像素），观感与原版一致，只是更糊 | 固定为面板的 2 倍；想更清晰只能提高底图分辨率，不要压倍数 |

| G4 ✅ | 切换物品后旧叠层残留（纪念币编号、终端服务标） | **真正原因**：叠层是按需「只增不减」的（SyncPanelMarks 等只 while 增，从不禁用多余层）。看完 6 位编号的纪念币再去看终端，6 个字符层仍显示着 | 新增 HideUnused(layers, used)：每次 Show 后把超出本轮数量的层 sprite=null; enabled=false。另外补 CloseUI 的 Postfix 兜底隐藏 |
| G5 ✅ | 纪念币大图偏大 | 纪念币底图是 224×102 的宽条，按 440 显示已是 1.96× 原生，镜片 ×2 后接近 4× | 纪念币单独用 320 见方（面板 1.43×、镜片 2.86×），其它物品仍 440 |

| G6 ✅ | 考官被赶走会不会卡状态 | 原版 DismissCurrentClient 只销毁柜台上的非自有物品（考卷），不通知模组；_active 会一直为真，之后别的顾客估价也被计入，三件后当场弹结算并锁当天预约 | 补 DismissCurrentClient / RemoveClientById 两个 Postfix 调 ExamSession.Cancel()；同时恢复「只统计 identifier 为 appraiserGuild 的顾客」过滤 |

## 排查入口（下次从哪看起）

1. **日志**：`%USERPROFILE%\AppData\LocalLow\Questing Goose Studio\Probably Stolen\Player.log`，搜 `AppraisalExpansion`
2. 关键行：
   - `考核开始：3 件…`（考官进队）
   - `考核记分：第 N 件…`（每件估价，带客户端 identifier）
   - `考核结束：… → 通过/未通过`（第三件之后）
   - `已收考试费 150` / `考核通过且已缴费：已发证书`
3. 如果**有记分没有结束** → 计数没到 3，查 E3。
4. 如果**有结束没有结算** → 查 E1（allDoneDialogue 是否被接上）。
5. 如果**结算出现但点了选项没反应** → 查 E2（结束时是否 `DismissCurrentClient` 抢走了焦点）。
