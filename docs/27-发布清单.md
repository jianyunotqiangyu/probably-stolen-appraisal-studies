### 游戏内回归（按顺序）

1. F9 `Exam Ready 100%` → 拨 `1717` 预约 → `Examiner Now`；
2. 估三件 → 点掉回应 → 结算对话 → 缴费 150 → 看证书与手册；
3. 依次鉴定四件物品，确认：面板大小合适、镜片 2×、编号/服务标显示正确；
4. 切换物品（纪念币 → 终端 → 指节），确认旧叠层不残留；
5. 退出鉴定，确认屏幕上无残留图层；
6. 选中物品时格子有高亮；两件纪念币不能叠在同一格。

## 六、版本号规则

每次对外发布（含修复）都要递增 <ModVersion>，并在 vdf 的 changenote 写清本次改动：

1. 改 mod/AppraisalExpansion/manifest.xml 的 <ModVersion>（唯一真源）；
2. 同步 vdf 描述里的「当前版本：vX.Y.Z」两处（中英）；
3. 更新 vdf 的 changenote；
4. 跑 	ools/make_dist.ps1（会自动读取 manifest 版本号并打 zip）。
