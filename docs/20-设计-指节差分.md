# 指节（民用义体指节）· 鉴定差分方案 v3

> 适用：初级鉴定师档，真值区间 35–180。
> v3 改动：碳纤维改为“钢”；不设伪品，只判价值；接口叠加层直接复用原版素材。

---

## 一、定位

- 初级 8 件里的“教学件”，检查点 **3 个主项**；
- 差分轴：材质 / 状态 / 接口，三轴组合，共 **27 种外观**；
- 所有物品只判价值，不设真伪判定。

---

## 二、差分轴与数值

基准价：**85**

| 轴 | 档位 | 修正 |
|---|---|---:|
| 材质 | 铝合金 | 0 |
|  | 钢 | +30 |
|  | 金（镀金） | +70 |
| 状态 | 正常 | 0 |
|  | 磨损（划痕、氧化） | −25 |
|  | 损坏（线缆外露、关节卡死） | −50 |
| 接口刻字 | 空白 | −15 |
|  | EMG | 0 |
|  | EMG+ | +15 |

真值公式：

```
value = max(35, 85 + 材质 + 状态 + 接口)
```

区间：

- 最高：85 + 70 + 0 + 15 = **170**
- 最低：85 + 0 − 50 − 15 = 20 → 压到 **35**
- 常见成交：**45–130**；镀金件稀有（约 5%）。

## 四、玩家读取流程（放大镜）

1. 拖放大镜 → 打开鉴定面板，显示指节大图；
2. 图上标 3 个热点：
   - 外壳 → 材质（铝 / 钢 / 金）
   - 关节缝隙 → 状态（正常 / 磨损 / 损坏）
   - 接口刻字 → 空白 / EMG / EMG+
3. 每个热点显示一行描述，例如“镀金外壳，高光偏亮”“刻字 EMG+，边缘清晰”；
4. 玩家从 85 起算，加减三项后提交；
5. 系统按 `getCorrectValue` 与提交值算偏差，给五档评语。

---

## 五、和考试/评语的衔接

- 考试品从 27 种组合里抽；
- “完美”= 落在正确价 ±5%；
- 只判价值：估偏高/偏低按评语档位处理，不再有“真伪错误”；
- 每件考试品只提交一次。
