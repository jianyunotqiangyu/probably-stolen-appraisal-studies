## 4. 标准操作流程

```powershell
# 1) 改完 src/ 后编译
pwsh -File mod\AppraisalExpansion\scripts\build.ps1

# 2) 只更新贴图（不加/删代码时）
pwsh -File mod\AppraisalExpansion\scripts\pack.ps1

# 3) 一条龙：编译 + 打包 + 部署到游戏目录
pwsh -File mod\AppraisalExpansion\scripts\deploy.ps1
```

游戏内验证：

1. 启动游戏 → Mod 页面确认 `AppraisalExpansion` 已启用；
2. **改了 dll 或 manifest 必须重新批准**（信任哈希变了），启用/禁用都要重启游戏；
3. `F8` 打开控制台，看 `[AppraisalExpansion]` 开头的日志；
4. 调试命令：
   - `knuckle-spawn <alu|steel|gold> <normal|wear|damage> <none|emg|emgplus> [count]` —— 直接摆到柜台上
   - `knuckle-customer <...> [count]` —— 排一个只带指定指节的鉴定顾客
5. 自查能力声明：F8 里运行 `mod-scan AppraisalExpansion`，要求 `declared` 覆盖 `detected` 且没有拒绝标记。

| **P22** | `PaperUI` ≠ `PaperUIPanel` | 两者名字接近：`PaperUI`（159673 行）管页面/翻页/页码，`PaperUIPanel`（161153 行）管面板层级。看字段名很容易判错 | 与 P21 同一教训。改手册行为前先 `grep "public class Paper"` 定位类边界 |
| **P23** | 同名键同时存在 `Textures\Paper` 与 `Textures\Items` 时，**双线性那份会赢** | `PaperAssets.FromMod` 的查找顺序是 **先 `PaperSprites` 再 `Sprites`**，旧的 `Textures\Paper` 残留会把点采样版本顶掉 | `pack.ps1` 每次生成前**整体清空 `Textures\`**；册子素材按类别放回各自目录（`paper` → `Textures\Paper`） |
| **P24** | 手册素材“糊”的根因是设计空间 ≠ 屏幕像素 | `PaperUI` 坐标是设计单位：`designWidth=314 / width=628` 时所有位图被放大 2 倍，`Textures\Paper` 又是 Bilinear | 把 `designWidth/Height` 设成与 `width/height` 相等（628×804），素材按最终尺寸出图 → 引擎不做重采样，1:1 |
| **P25** | `fontSize` 是设计单位，不是屏幕像素 | 314 设计空间下 `9` 号字 = 屏幕 18 px；改成 628 空间后写 `18` 仍是 18 px，所以“改字号没变化”是正常的 | 设计空间翻倍时字号一起翻倍；要更大就给更大的数（当前页码 30） |
| **P26** | `translations` 按 locale code **精确匹配** | `ResolveText` 用 `LocHelper.GetCurrentLocaleCode()` 取 Unity `Locale.Identifier.Code`，简体中文是 `zh-Hans`，官方指南表格里写的是 `zh` | 每个多语言文本同时写 `"zh-Hans"` 与 `"zh"` |
| **P27** | 批量字符串替换会误伤同值元素 | 把 `"fontSize": 26` 替换成 `30` 时，标题的 26 也被一起改了（页码与标题撞值） | 改单个元素时带上下文替换（前后键名/坐标），改完 `grep` 复核 |
| **P28** | 用到 `TextMeshProUGUI` 要加程序集引用 | `csc` 报 `CS0012: 类型 TextMeshProUGUI 在未引用的程序集中定义` | `build.ps1` 的 `$refs` 加 `Unity.TextMeshPro.dll`（游戏自带，不打包） |
| **P29** | 模板 `slot` 不支持 `translations` | `ResolveText` 里 `slot` 优先级最高且只返回字符串，翻译链被跳过 | 要双语就别用模板：header/title/flow/body 直接写进页面元素 |
| **P30** | 原版 0.46D **没有** `PaperAssetCatalog` | `PaperAssets` 第 3 步永远拿不到，
otebook_manual` / `guide_logo` / `paper_buttons_*` 这些原版键在运行时解析不出来 | 要用就导出成模组素材自带（`reference\vanilla-paper\` → `assets\paper\`） |

## 8. 素材规格（给美术 / 自绘都按这个来）

| 类别 | 尺寸 | 要求 |
|---|---|---|
| 物品图标 `icon` | 16 的整数倍；指节用 16×32（= 1×2 格，`UISettings.gridSize = 16`） | RGBA 透明背景，硬边缘像素风（游戏按 Point 过滤加载，不要依赖抗锯齿）。**只按材质分模，不画状态/接口**（见 P11） |
| 鉴定大图底图 `magnifier_base` | 256×256 | 放大镜里看的大图，按“材质 × 状态”出 9 张；画布必须一致、内容对齐（当前 9 张 alpha 包围盒都是 `71,54,185,202`） |
| 接口叠层 `magnifier_overlay` | 256×256 | 只画接口标记，其余全透明；叠在底图上（当前 `emg` 158 px、`emgplus` 129 px，全部落在底图轮廓内） |
| 纸质手册 `paper` | **628×804 背景 / 28×30 按钮 / 188×236 插图** | 设计空间 = 屏幕像素，1:1 摆放；`Textures/Paper` 是双线性，别再让引擎放大（P24） |
| 音效 | `.wav` / `.ogg` / `.mp3` | 放 `assets/sounds/` |

> 不透明像素决定物品占几格（透明区域=空格子）。`.png` 必须是 16 的整数倍，否则 `BuildShapeFromSprite` 会报 `SPRITE NOT ON GRID`。
