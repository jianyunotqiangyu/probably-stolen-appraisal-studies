> 适用：初级鉴定师档第 3 件。
> 与已完成的指节、检测仪同一套写法：三轴 Tag、价格按轴累加、大图用「底图 + 叠层」拼。
> v3（2026-11-17）：新增「未开通」服务档（0 价），服务轴变成四档，组合 24 种。

## 一、定位

- 初级 8 件里的第 **3** 件，检查点 3 个主项；
- 差分轴：**品相 / 材质 / 支持服务**，3 × 2 × 4 = **24 种外观**；
- 与另两件的区别：
  - 指节看「材质 / 关节 / 接口刻字」，上限 170；
  - 检测仪看「传感器 / 机身 / 插件 / 厂商」，上限 250；
  - 终端看「品相 / 材质 / 服务」，**上限 620**——它是三件里最贵的一件。

## 二、差分轴与数值

基准价：**100**

| 轴 | 档位 | 修正 | 外观 |
|---|---|---:|---|
| 品相 | 全新 | 0 | `wrist_*_new` |
|  | 磨损 | −20 | `wrist_*_worn` |
|  | 损坏 | −40 | `wrist_*_damaged` |
| 材质 | 铸铁 | 0 | `wrist_iron_*`，小图标 `wrist_icon_iron` |
|  | 镀金 | +200 | `wrist_gold_*`，小图标 `wrist_icon_gold` |
| 支持服务 | 未开通 | 0 | 无叠层 |
|  | 卫星中继 | +40 | `wrist_service_relay` |
|  | 加密通信 | +50 | `wrist_service_crypt` |
|  | 双服务 | +120 | `wrist_service_both`（整图一张） |

真值公式：

```
value = max(40, 100 + 品相 + 材质 + 服务 [+200 轻奢套装])
轻奢套装 = 全新 && 镀金 && (卫星中继 || 双服务)
```

区间：

- 最低：100 − 40（损坏）+ 0 + 0（未开通）= **60**
- 铸铁全新未开通：**100**
- 非套装最高（磨损 + 镀金 + 双服务）：100 − 20 + 200 + 120 = **400**
- 轻奢套装：+200 → **540**（中继）/ **620**（双服务）

> 底线 40 在本件上不会触发（最低 60），保留常量只是为了与其他两件写法一致。
> 若觉得终端比另两件贵太多，把 `BaseValue` 调低即可（一个常量）。

## 三、权重（各轴合计 100）

| 轴 | 权重 |
|---|---|
| 品相 | 全新 65 / 磨损 25 / 损坏 10 |
| 材质 | 铸铁 80 / 镀金 20 |
| 服务 | 未开通 15 / 中继 35 / 加密 30 / 双服务 20 |

轻奢套装出现率 ≈ 65% × 20% ×（35% + 20%）≈ **7.2%**；顶价件（620）≈ 65% × 20% × 20% ≈ **2.6%**。

## 五、判定方法（写手册时用）

| 轴 | 怎么看 |
|---|---|
| 品相 | 全新屏幕无痕、按键回弹正常；磨损有细划痕、边缘涂层磨白；损坏屏幕开裂或按键缺失 |
| 材质 | 铸铁哑光偏冷、高光宽而柔；镀金偏暖、高光向边缘减弱、转角露基材纹理 |
| 服务 | 机身左侧两枚服务标：中继、加密；两枚同时具备按双服务计 |
