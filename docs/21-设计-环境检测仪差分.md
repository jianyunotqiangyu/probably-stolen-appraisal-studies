> 适用：初级鉴定师档。
> v2：第三轴由「内容拓展（3 档）」改为「拓展插件（4 档，双插件 = 两张叠层同时叠）」，

## 一、定位

- 初级 8 件里的第 **2** 件，检查点 4 个主项；
- 差分轴：**传感器状态 / 机身品相 / 拓展插件 / 生产厂商**；
- 外观组合 = 3 × 3 × 4 × 3 = **108 种**，但图像只有 9 张底图 + 2 张插件 + 2 张厂商标，
  靠「底图 + 0~3 层叠层」拼出来。

## 二、差分轴与数值

基准价：**100**

| 轴 | 档位 | 修正 | 外观 |
|---|---|---:|---|
| 传感器状态 | 正常 | 0 | `envscan_*_ok` |
|  | 偏移 | −20 | `envscan_*_drift` |
|  | 失效 | −40 | `envscan_*_dead` |
| 机身品相 | 良好 | 0 | `envscan_good_*` |
|  | 磨损 | −5 | `envscan_worn_*` |
|  | 破损 | −20 | `envscan_broken_*` |
| 拓展插件 | 无 | 0 | 无叠层 |
|  | 空气插件 | +10 | `envscan_plugin_air` |
|  | 病菌插件 | +15 | `envscan_plugin_bio` |
|  | 空气＋病菌（双插件） | +30 | 两张叠层同时叠 |
| 生产厂商 | 无 | 0 | 无叠层 |
|  | 蒸汽机械 | +10 | `envscan_vendor_steam` |
|  | 鲁班科技 | +20 | `envscan_vendor_luban` |

真值公式：

```
value = max(40, 100 + 传感器 + 机身 + 插件 + 厂商 + 套装)
套装：正常 + 良好 + 双插件 + 有厂商标 → +100，名字显示为「顶配套装」
```

区间：

- 非套装最高：100 + 0 + 0 + 15（病菌）+ 20（鲁班）= **135**
- 实测非套装区间：**40 – 145**
- 最低：100 − 40（失效）− 20（破损）= **40**，正好落在底线上
- 顶配套装：240（蒸汽机械）/ **250**（鲁班科技），出现率约 3.1%

> “顶配套装”只是手册里的称呼，**不改物品名**（2026-11-10 决定）。
> 250 仍高于初级 35–180 的常规区间，属于刻意保留的收集向高点。

## 三、权重（各轴合计 100）

| 轴 | 权重 |
|---|---|
| 传感器 | 正常 70 / 偏移 25 / 失效 5 |
| 机身 | 良好 65 / 磨损 28 / 破损 7 |
| 插件 | 无 30 / 空气 30 / 病菌 25 / 双插件 15 |
| 厂商 | 无 55 / 蒸汽机械 25 / 鲁班科技 20 |

套装出现率 ≈ 0.70 × 0.65 × 0.15 × 0.45 ≈ **3.1%**；
带插件（不含“无”）的概率 70%，带厂商标 45%。
