# 鉴定行会名片 · 设计 v1

> 第 4 件「纸质物品」，与三本手册同一套 PaperUI 机制。

---

## 一、定位

- 玩家在鉴定公告板完成入会对话后，柜台上自动出现；
- 作用是**身份凭证**：证明鉴定资格，并印上行会的预约号码；
- 未来接线的入口：名片上的号码 `1717` 就是电话拨号要拨的号。

## 二、形态

| 项 | 值 |
|---|---|
| 背景 | 原版 `business_card_template`（200×125 空白米色卡面） |
| 设计空间 | 200×125（与原版卡面 1:1） |
| 显示尺寸 | 400×250（2 倍放大；文字是矢量的，不糊） |
| 页数 | 1 页，无翻页 |
| 外框 | 只有关闭按钮 |
| 打开方式 | **双击物品**（PaperUI 自带，与手册相同） |

卡面内容（设计坐标）：

| 位置 | 内容 | 字号 |
|---|---|---|
| y=9 | 空间站贸易委员会（抬头，蓝） | 8 |
| y=24 | 鉴定行会（主标，蓝） | 17 |
| y=50 | 分隔线 24→176 | 1px |
| y=58/74/90 | 左栏：持证人 / 预约考官 / 鉴定等级 | 8 |
| y=72 | 右栏：**1717**（主视觉，蓝） | 13 |
| y=106 | 凭此卡预约鉴定考官 · 请勿转借 | 8 |

## 三、发放逻辑

沿用 `GuildCard.EnsureGiven()`：

1. `PlayerStore.isAppraisalIntroduced` 为真（已入会）；
2. `EmporiumEntry.GetItemCountById("appraiser_card") <= 0`（柜台上还没有）；
3. 两条都满足就 `AddDirectSellingItemToTable("appraiser_card", isOwend: true)`。

触发点：`ModHook.OnGameLoadedLate`（读档后）+ `ModHook.OnShutterOpenedEarly`（每天开店）。

## 四、实现要点（与旧版不同）

| 旧做法 | 现做法 | 原因 |
|---|---|---|
| `GuildCard.Create()` 手写物品工厂 + `dir.Add` 注册 | **删掉**，由 `Books/appraiser_card.json` 的 `item` 段声明 | 手册物品本来就是书系统注册的；同一 ID 不能注册两次，且书系统才会挂上 `contentWindow`（双击才打得开） |
| 16×16 占位图标 | 保留 `Textures/Items/appraiser_card.png` 作为**背包图标**，卡面用原版底图 | 图标和卡面是两回事 |

生成脚本：`tools/build_appraiser_card.py`（不手改 JSON）。
